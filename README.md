# CRE address redirects

This public GitHub Pages repository preserves old `imsamguys.github.io/cre/` links after the main CRE repository moved to private GitHub hosting. The site and Studio run on [Vercel](https://cre-cre2.vercel.app/). The [local engine download](https://github.com/imsamguys/cre-downloads/releases/latest) is maintained separately.

The redirect keeps the URL path, query string, and fragment so existing account links can reach the matching Vercel page.
